# ECON 5560 replication: Shah et al. (2019)

Individual replication repository for ECON S5560 (Cal Poly, Fall 2026), Liam Hyde. It reruns my team's (Team 1) replication from the raw data to the final tables and figure with one command.

## Paper

Shah, P., Dissanayake, S. T. M., Fujita, Y., and Nunes, P. A. L. D. (2019). Impact of a local, coastal community based management regime when defining marine protected areas: Empirical results from a study in Okinawa, Japan. *PLOS ONE*, 14(3), e0213354. https://doi.org/10.1371/journal.pone.0213354

The paper is a split-sample choice experiment with Okinawa residents. Half saw a nationally managed (top-down) marine protected area, half a community-managed (bottom-up) one. It fits mixed logit models (Table 3) and turns them into willingness to pay (WTP, Table 4). The headline result is that WTP for the protected-area attributes is higher under community management.

## Data

Both files in `data/raw/` are exactly as obtained; the first script checks their SHA-256 hashes before anything runs.

- `data_impact_community_based_mgt_on_MPAs.dta`: the authors' replication data, Harvard Dataverse, https://doi.org/10.7910/DVN/OELWEF (CC0). Downloaded 2026-09-25. It has no variable recording which alternative each respondent chose, so the paper's models cannot be estimated from it alone.
- `MPA_journal_data_with_choice_for_CalPolyFA2026.xlsx`: the same data with the observed choice added (`Choice`, `Alt`), prepared for this course and received by our team on 2026-10-26. It is not publicly posted elsewhere. The script checks that its 19 shared columns are identical to the Dataverse file.

Neither file is over 50 MB (1.2 MB and 0.6 MB).

## How to run

Requires Python 3.13 (3.11 or newer should work) and the packages in `requirements.txt`. From the repo root:

```
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
python run_all.py > logs/run_log.txt 2>&1
pip freeze > logs/requirements.txt
```

`run_all.py` runs the four scripts in `code/` in order and stops at the first error. Its last lines print the Python version, platform and package versions (Python's equivalent of `sessionInfo()`).

## Files

- `run_all.py`: master script; runs every step below in order and prints session info.
- `requirements.txt`: pinned Python package versions.
- `code/01_check_data.py`: checks file hashes, panel structure, and that the two data files agree; writes `outputs/data_checks.csv`.
- `code/02_table2_descriptives.py`: reproduces Table 2 (respondent characteristics by survey version); writes `outputs/table2_descriptives.csv` and `outputs/table2_income_sensitivity.csv`.
- `code/03_mixed_logit_tables3_4.py`: estimates Models 1 and 2 (Table 3) and WTP (Table 4) next to the published values; writes `outputs/table3_coefficients.csv`, `outputs/table4_wtp.csv` and `outputs/model_summary.json`.
- `code/04_figure1_wtp.py`: draws attribute WTP by management regime, ours beside the paper's; writes `outputs/figure1_wtp.png` and `.pdf`.
- `data/raw/`: the two raw data files described above.
- `outputs/`: everything the scripts produce; regenerated by `run_all.py`.
- `logs/run_log.txt`: full output of the clean run described below.
- `logs/requirements.txt`: `pip freeze` from that run.

## What did and did not reproduce

Table 2 reproduces: all ten group means match the paper to two decimals. The age standard deviation matches the population SD (9.78 and 9.36); the sample SD is 9.79 and 9.37, and the paper does not say which it used. Income is a category code 1 to 6, and code 6 means "don't know / no answer"; the paper's means only come out if code 6 is kept as a number, so I keep it and report the mean without it in `table2_income_sensitivity.csv`.

The sample is 824 respondents (422 national, 402 community), not the paper's 827. The posted data are short three community respondents, and I could not find them.

Table 3 mostly reproduces. In both models every main-effect attribute and payment coefficient is within 0.0003 of the published value with the same significance level. The three attribute × community interactions in Model 2 are within 0.003 with the same signs and significance levels. The ASC (the value of any protected area over the status quo) does not: 7.61 vs 8.22 in Model 1 and 7.55 vs 8.46 in Model 2. ASC × community is 0.98 and significant (paper: 0.225, not significant), and payment × community is −0.0004 and not significant (paper: −0.0011, significant at 5%).

Table 4 mostly reproduces. Attribute WTPs are within about 15% of the paper, and WTP is higher under community management for all three attributes, as the paper finds. The ASC WTPs do not: Model 1 and the Model 2 national value are 9% and 14% below the paper's, and the community value is 7% above it, so the community ASC WTP comes out above the national one, the reverse of the paper's order. My team reran these models with 500, 1,000 and 2,000 Halton draws and with pseudo-random draws under three seeds (in our team repo), and the ASC terms moved by about as much as these gaps, so they are most likely simulation noise. The paper does not report its software or number of draws, so I could not match those.

Table 5 (the marginal rate of substitution between natural and man-made capital) is not replicated here.

Software: my team first estimated these models in R with `mlogit` (Zoey Miles's specification). R packages could not be installed from CRAN on the machine used for the clean run, so this repo uses the team's Python port with `xlogit`. With the same 500 Halton draws, the team found the two agree on every coefficient and standard error to within 1e-7 of a standard error.
